# ClaimWise SG 总评估报告

评估日期：2026 年 11 月 7 日。正确性检查通过；持续负载达到实验目标，最新突发测试未达标；问卷数据属于合成演示。

## 1. 决策正确性

**18 个决策案例全部通过**，与独立参照计算逐项比对 NCD 路径、免赔额、成本和推荐结果。本地 HTTP 检查 **26/26 通过**，包含上述案例及 8 个无效请求。这验证了既定假设下的程序实现，不代表已验证每份保险合同或实际未来保费。

## 2. HTTP 性能

测试针对已部署的 Cloud Run 服务，计算请求均关闭保存。“发起跨度”指首次到末次客户端 HTTP 调用开始的间隔，不是数据上传耗时或服务器收到请求的时间跨度。

### 持续负载

三项分别运行：先以 5 个虚拟用户预热 10 秒，再以 **50 个虚拟用户测量 60 秒**。统计排除预热，允许已开始的流程执行完毕。

| 操作 | 具体测试操作 | 平均延迟（毫秒） | P95（毫秒） | 最大延迟（毫秒） |
| --- | --- | ---: | ---: | ---: |
| 获取页面 | 5718 次 GET；发起跨度 59.968 秒 | 25.91 | 65.21 | 435.69 |
| 决策接口 | 5702 次 POST；发起跨度 59.989 秒 | 28.50 | 97.73 | 566.74 |
| 页面→决策 | 5507 个流程／11014 次请求；发起跨度 60.006 秒 | 49.46 | 120.16 | 344.11 |

吞吐量分别为**页面 95.3 次/秒、决策 95.0 次/秒、流程 91.8 个/秒**。错误率均为 0%，达到单接口 P95 小于 250 毫秒、流程 P95 小于 500 毫秒的实验目标。

### 突发负载

以下三行统一来自**最新一批 200 个有序流程**，不是三次独立突发实验。每个 POST 都等待自己的 GET 成功后再发起。本轮无健康检查、无预热，距最后记录的客户端压测间隔 31.92 分钟。

| 操作 | 具体测试操作 | 平均延迟（毫秒） | P95（毫秒） | 最大延迟（毫秒） |
